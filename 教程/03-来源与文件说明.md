# 来源、版本与文件说明

版本：**1.0.0 正式版（Windows CPU 部署包）**。插件、模型服务和部署脚本统一为这个版本。

相对之前私下分发的测试包（1.1.0 / 1.1.1）：

- 修复首次自动启动常报“启动超时”、多试几次才可用的问题。Windows 解析 `localhost` 时先试 IPv6 `::1`，服务原先只监听 IPv4，每次新连接要先等约 2 秒，而启动等待中的单次检查只给 1 秒。现在服务同时监听本机 IPv4 和 IPv6 回环地址，单次检查超时放宽到 5 秒。
- 模型权重不再随包分发，部署时从原作者仓库下载并校验。

用过测试包的人请在新文件夹重新部署，并安装新生成的插件；插件 ID 不变，新版会替换旧版。

## 模型

- 名称：Manga-Text-Segmentation-2025。
- 原作者仓库：[a-b-c-x-y-z / Manga-Text-Segmentation-2025](https://huggingface.co/a-b-c-x-y-z/Manga-Text-Segmentation-2025)。
- 模型结构：U-Net++，EfficientNetV2 骨干。
- 固定 revision：`2dde9eeb03e81692c1562059451c2bf30e1a13da`。
- 权重大小：216,911,417 字节。
- 权重 SHA256：`a0a895dc385608554a81ca765b0c62d654462c2bac661abdff63634985ab37fc`。
- CPU 加载使用 `weights_only=True`、完整参数严格匹配，不下载额外 ImageNet 权重。

原模型页面提供了论文及数据集引用，模型和训练资料的权利归原作者及各自权利人。本项目不分发原权重，只记录来源、固定版本和校验值，由使用者部署时从原仓库下载，也不给原权重附加自创许可证；截至整理时，模型卡没有明确的许可证元数据，相关使用条件请查看原仓库及作者说明。包内没有漫画训练数据或开发者的测试漫画。

## 程序

| 文件 | 用途 |
| --- | --- |
| `deploy.py` | 创建环境、安装固定依赖、准备本机插件并验证。 |
| `prepare_plugin.py` | 写入本机模型路径，生成控制许可，重新打包 CCX。 |
| `check_deployment.py` | 验证依赖、权重、路径、真实模型推理及接口。 |
| `bootstrap.ps1` | 给双击脚本寻找完整 Python 3.12 x64，使用 Windows 自带 PowerShell。 |
| `payload-sha256.json` | 发布时不可变文件的 SHA256 清单；运行生成的配置、CCX 不在此清单中。 |
| `Manga-Text-Segmentation/app.py` | 中文网页单张/批量处理与本地模型。 |
| `Manga-Text-Segmentation/ps_api.py` | 本机 RGB 输入、灰度掩膜输出、接管及关闭接口。 |
| `Manga-Text-Segmentation/model_lifecycle.py` | 检查当前会话的 Photoshop 进程，在退出后关闭自己的服务。 |
| `Manga-Text-Segmentation/launch.py` | 复用或后台启动模型，避免重复加载。 |
| `Manga-Text-Segmentation/start-hidden.vbs` | 由 PS 授权后隐藏启动模型。 |
| `PS-Manga-Text-Selection/plugin/` | Photoshop UXP 插件源码。 |
| `PS-Manga-Text-Selection/漫画文字选区.ccx` | 初始是未绑定模板，部署后被本机有效安装包替换。 |

`.venv`、`.control-token`、`deploy.log`、`server.pid`、服务日志、`cache`、`results` 和本机插件配置会在部署或运行后生成。它们不应从发送者电脑直接搬过来。本包没有发送者的运行环境、漫画、输出、日志或私有控制许可。

模型运行仅监听本机回环地址 `127.0.0.1:7860` 和 `[::1]:7860`（电脑不支持 IPv6 时只用前者），不对局域网开放；插件网络权限仅允许 `localhost`。打开 `.vbs` 的权限用于启动这个本地模型。关闭和接管接口使用本机新生成的控制许可，该许可不会由健康接口公开。
