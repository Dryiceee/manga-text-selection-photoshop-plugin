漫画文字选区 · Photoshop 插件

Manga Text Selection for Adobe Photoshop：先用矩形或套索建立选区，点击“选中区域内文字”，由本机运行的漫画文字分割模型选中该范围内的文字笔画像素。只修改选区，不修改图片，可以 Ctrl+Z 撤销。不做 OCR、翻译或背景修复。

v1.0.0 · Windows x64 + CPU · Photoshop 25.0 或更高版本。 本项目包含插件、本地模型服务、部署脚本和中文教程；模型权重来自原作者的 Manga-Text-Segmentation-2025，不随本项目分发，部署时按固定版本下载并校验。首次部署需要联网下载 Python 依赖和权重。

自己部署

  1. 从 GitHub Releases 下载 Manga-Text-Selection-v1.0.0.zip，完整解压到较短的固定文件夹，例如 D:\MangaText。
  2. 按教程安装 Python 3.12 x64。
  3. 双击 01-安装部署.cmd，等待“部署检查通过”。
  4. 双击 03-安装PS插件.cmd 或安装刚生成的 .ccx。
  5. 在 PS 里建立选区，打开插件面板，点击“选中区域内文字”。

先部署，再安装插件。 部署会把安装包里的模型位置绑定到你自己的电脑。移动文件夹后，重新生成并重新安装插件。整个文件夹需要保留。

功能

  • 只选中原选区范围内的文字笔画像素，保留套索和羽化限制。
  • 模型没开时自动启动；面板可手动关闭模型。
  • 退出全部 PS 后自动关闭模型，下一次检测自动再启动。
  • 也提供本地网页单张/批量处理。

来源、版本与文件说明
